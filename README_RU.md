# Pristal VPN

**Pristal VPN** — экспериментальная бесплатная программа для Windows 10/11, которая собирает публичные HTTP- и SOCKS5-прокси, проверяет доступность их TCP-портов и может запускать выбранный прокси через [sing-box](https://github.com/SagerNet/sing-box).

> **Важно:** это пока менеджер прокси, а не полноценный VPN. Программа включает системный HTTP-прокси Windows. Его используют только приложения, которые поддерживают системные настройки прокси. Многие игры и UDP-приложения могут работать напрямую.

## Возможности

- Интерфейс на русском языке.
- Получение публичных HTTP/SOCKS5-списков из открытых репозиториев.
- Сортировка по времени TCP-подключения к серверу.
- Запуск выбранного прокси через sing-box.
- Настройка системного прокси Windows на `127.0.0.1:2080`.
- Восстановление прежних настроек при штатном нажатии «Остановить».
- Экспорт найденных адресов в CSV.

## Скачать готовую версию для Windows

1. Откройте вкладку **Actions** репозитория и выберите **Build Windows EXE**.
2. Нажмите **Run workflow** и дождитесь завершения сборки.
3. Внизу страницы успешного запуска скачайте артефакт **PristalVPN-Windows-x64**.
4. Распакуйте ZIP в отдельную папку.
5. В папке должны находиться оба файла: `PristalVPN.exe` и `sing-box.exe`.
6. Запустите `PristalVPN.exe`.

Workflow автоматически загружает официальный стабильный релиз sing-box для Windows AMD64 и кладёт его рядом с приложением. **Не разносите эти два EXE по разным папкам.**

## Запуск из исходного кода

1. Скачайте репозиторий кнопкой **Code → Download ZIP** или клонируйте его.
2. Установите Python с [официального сайта](https://www.python.org/downloads/windows/).
3. Скачайте официальный архив sing-box для Windows AMD64.
4. Извлеките `sing-box.exe` в ту же папку, где находится `PristalVPN.py`.
5. Запустите `run.bat` или выполните `py -3 PristalVPN.py` в командной строке.

## Локальная сборка EXE

Откройте PowerShell в папке проекта:

```powershell
py -m pip install pyinstaller
py -m PyInstaller --onefile --windowed --name PristalVPN PristalVPN.py
```

Скопируйте официальный `sing-box.exe` для Windows AMD64 рядом с `dist\\PristalVPN.exe`. В собранном приложении движок ищется рядом с EXE.

## Безопасность и ограничения

- Публичные прокси принадлежат неизвестным операторам. Они могут собирать метаданные, быть нестабильными или перехватывать незашифрованный трафик. Не используйте публичные прокси для банков, платежей, паролей и чувствительных аккаунтов.
- Проверка TCP-порта **не подтверждает**, что протокол прокси работает, что сервер безопасен или что он обеспечивает анонимность.
- Показанное время — только время TCP-подключения к адресу прокси, а не игровой пинг и не задержка до сайта.
- В текущей версии нет TUN-интерфейса, kill switch или защиты от DNS-утечек.
- Списки прокси предоставляются сторонними сообществами и могут изменяться или исчезать.
